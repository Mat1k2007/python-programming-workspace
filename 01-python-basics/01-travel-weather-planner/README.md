# Travel Weather Planner

A lightweight Python script that evaluates clothing recommendations and travel advice based on weather input logic.

## Implementation Details
This project relies strictly on foundational Python concepts:
- **Input Processing:** Handles variable assignments and input evaluations.
- **Conditional Decision Trees:** Uses `if`, `elif`, and `else` blocks to compare weather conditions and temperature limits.
- **Output Formatting:** Displays tailored travel suggestions via formatted string outputs.
