# Caesar Cipher

A Python script that implements text encryption and decryption using the classic Caesar Cipher algorithm logic.

## Implementation Details
This project relies strictly on foundational Python concepts:
- **Functional Scope:** Encapsulates shift calculations within modular function definitions.
- **Input Validation:** Enforces correct operation modes (`encrypt` vs. `decrypt`) using conditional logic.
- **String Handling:** Formats and displays output using standard string techniques and f-strings.
